INPUTS PUBLICADOS EN payments.aggregates.v1
------------------------------------------------------------

Publicados con kafka-python (KafkaProducer).
Kafka key = aggregate["key"].encode("utf-8") en los tres mensajes.
Campos comunes de cada aggregate:
    schema_version = 1
    window_start   = "2026-01-01T12:00:00.000Z"
    window_end     = "2026-01-01T12:01:00.000Z"

Input 1:
    key               = merchant-001|2026-01-01T12:00:00.000Z
    transaction_count = 1
    total_amount_pyg  = 10000
    partition         = 0
    offset            = 0

Input 2:
    key               = merchant-001|2026-01-01T12:00:00.000Z
    transaction_count = 2
    total_amount_pyg  = 35000
    partition         = 0
    offset            = 1

Input 3:
    key               = merchant-002|2026-01-01T12:00:00.000Z
    transaction_count = 1
    total_amount_pyg  = 5000
    partition         = 0
    offset            = 2

Producer: 3 sends + flush confirmados.
Los 3 mensajes cayeron en la particion 0. Input 1 e Input 2 comparten la
misma key -> misma particion -> orden garantizado (offset 0 antes que
offset 1): el segundo pane de merchant-001 se aplica despues del primero.
